# MyBlog
A blog which I am using to post my acheivements and interesting posts about coding.

# Project Overview

The entire project is splitted to two subRepos, which are combined into the project by the infra repo. Click onto links to go to the individual subRepos.

| Service       | Description                                    | Repository URL                     |
|---------------|------------------------------------------------|------------------------------------|
| **Frontend**  | Very simple frontend app written in Vue| [Frontend Repo](https://github.com/Litenoo/MyBlogFrontend) |
| **Backend**   | The Backend app written it TS+node | [Backend Repo](https://github.com/Litenoo/MyBlogBackend)   |
| **Infra**     | The repo which merges both of Backend and Frontend submodules into project |[Infra Repo (current)](https://github.com/Litenoo/MyBlog/)  |
